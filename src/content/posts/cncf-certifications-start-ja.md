## AIを使うことと、実際に分かっていることの境界

CNCFの技術は本当にたくさんありますが、会社でも主に使っている技術です。Kubernetesから始まって、Helm、Prometheus、containerd、CoreDNS、Envoyまで、クラスターを一つ立てるだけでCNCFのプロジェクトをいくつも使うことになりますからね。

普段の業務では、正直なところ必要な部分だけ調べて使うか、最近ではAIに調査ごと任せてしまいますよね。「このnamespaceでPodがなぜ再起動を繰り返しているのか原因を調べて」といった指示を出せば、AIが`kubectl describe`やログを調べて、結論まで自然な言葉で分かりやすく説明してくれますし、速いですから。

このブログ記事もAIで最終チェックをしているくらいなので、AIを使っていて本当に分かっていると言えるのか、といったやや？時代遅れな話をしたいわけではありません。

ただ、仕事にもある程度慣れてきて、理論をもう少し知りたいと思うようになりました。

私は新しい言語や技術を学ぶときも、理論からではなくチュートリアルから入るタイプなんです。

実務でも、よく使うコマンドやHelm chart、YAMLの修正から始めてきましたから。

例えば、init containerという概念を知らない状態で、AIに「アプリケーションが起動する前に、DB接続が正常にできるかを先に確認したい」と頼んだとしましょう。AIがinit containerを勧めてくれても、それが何なのかを理解するのにもう一手間かかります。逆にAIがアプリケーションのコードに接続リトライのロジックを入れようと提案してきたら、Kubernetes側で解決する方法が別にあることに気づきにくいでしょう。

似て見えるprobeとも混同しやすいです。startup probeはアプリケーションが起動しきったかを、readiness probeはトラフィックを受けても大丈夫かを確認し、init containerはアプリケーションのコンテナが起動する前に先に実行されて終わっている必要がある処理です。この違いを知らないと、AIが出した答えが正しいかを判断するのに時間がかかってしまいます。

本当に「分かって」いるなら、使い方はすぐに思い出せなくても、「こんな概念があったな」くらいは頭に浮かぶべきではないか。そう思ったんです。

## CNCF資格

AIの時代に、こういう資格にまだ意味があるのか？という正直な疑問もあります。それにCNCFの資格って、決して安くはないですよね？

有効期間が2年なうえに、Kubernetes以外の資格まで含めると10個を超えるので、正直ちょっと大変です。

それでも資格の勉強をしてみようと思ったのは、先ほど話した理論の勉強のためでもありますし、会社が資格2つ分を支援してくれるというのも大きいです。

ひとまず目標は、後で触れるKubestronautに設定しました。

### CNCF資格はどう分かれているのか

CNCF資格、正確にはCNCF（Cloud Native Computing Foundation）とLinux Foundationが共同で運営しているKubernetes資格は、5つあるそうです。

| 資格                                                  | 内容                               | 形式                |
| ----------------------------------------------------- | ---------------------------------- | ------------------- |
| KCNA (Kubernetes and Cloud Native Associate)          | 入門。クラウドネイティブ全般の概念 | 選択式              |
| KCSA (Kubernetes and Cloud Native Security Associate) | 入門。セキュリティの概念           | 選択式              |
| CKA (Certified Kubernetes Administrator)              | クラスターの運用・管理             | 実技                |
| CKAD (Certified Kubernetes Application Developer)     | アプリケーションのデプロイ・設計   | 実技                |
| CKS (Certified Kubernetes Security Specialist)        | クラスターのセキュリティ           | 実技、CKA保有が必要 |

5つすべてを有効な状態で持っていると、**Kubestronaut**という称号がもらえます。2年以内に全部そろえる必要があるということですね。

### 順番

CKSはCKAを持っていないと受けられませんが、それ以外は自由です。私は**CKAD、CKA**を会社の支援で受けてみるつもりです。

CKADなら普段の業務とも近いので、まずはCKADから始めてみたいと思いました。

その後CKAの準備をして、2026年11月に定期セールがあるそうなので、そのころにCKSとKCNA、KCSAを自費で受けてみようと思います。
